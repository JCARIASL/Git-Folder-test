🐍 Tutorial: Entorno Python

Instalación paso a paso de VS Code + Jupyter + Git + Live Server

🐍 Paso 1: Instalar Python

Instrucciones:

  1. Ve a la página oficial: https://www.python.org/downloads/
  2. Descarga la última versión estable (recomendado 3.11 o superior)
  3. Ejecuta el instalador descargado
  4. ⚠️ MUY IMPORTANTE: Marca la casilla "Add Python to PATH" antes de instalar
  5. Selecciona "Install Now"
  6. Abre una terminal (CMD o PowerShell) y verifica:
    python --version
    pip --version

💻 Paso 2: Instalar VS Code + Extensión Python

Instrucciones:

  1. Descarga VS Code desde: https://code.visualstudio.com/
  2. Durante la instalación marca:
    • "Add to PATH"
    • "Add 'Open with Code' a Windows Explorer"
  3. Abre VS Code y ve al panel de Extensiones (Ctrl + Shift + X)
  4. Busca e instala: "Python" (de Microsoft)
  5. Abre la paleta de comandos (Ctrl + Shift + P) y ejecuta:
    Python: Select Interpreter
  6. Elige la versión de Python que instalaste

📓 Paso 3: Configurar Jupyter en VS Code

Instrucciones:

  1. En VS Code, instala estas extensiones:
    • Jupyter (Microsoft)
    • Jupyter Keymap (opcional)
    • Jupyter Notebook Renderers (Microsoft)
  2. Abre la terminal integrada en VS Code (Ctrl + ñ o Ctrl + `)
  3. Instala los paquetes necesarios:
    pip install jupyter ipykernel
  4. Crea un archivo nuevo con extensión .ipynb (ejemplo: notas.ipynb)
  5. VS Code lo abrirá como un notebook de Jupyter
  6. Arriba a la derecha, selecciona el kernel de Python
  7. ¡Listo! Ya puedes crear celdas con código y ejecutarlas con Shift + Enter

🌿 Paso 4: Instalar y Configurar Git

Instrucciones:

  1. Descarga Git desde: https://git-scm.com/downloads
  2. Ejecuta el instalador (opciones por defecto están bien)
  3. Verifica la instalación en terminal:
    git --version
  4. Configura tu identidad (una sola vez):
    git config --global user.name "Tu Nombre"
    git config --global user.email "tu@email.com"
  5. En VS Code instala la extensión "GitLens" (recomendada)
  6. Git se integra automáticamente en la barra lateral de VS Code (icono de ramificaciones)

🌐 Paso 5: Extensión Live Server

Instrucciones:

  1. En VS Code ve a Extensiones (Ctrl + Shift + X)
  2. Busca e instala: "Live Server" (autor: Ritwick Dey)
  3. Crea un archivo HTML en tu proyecto, por ejemplo: index.html
  4. Haz clic derecho dentro del editor y selecciona: "Open with Live Server"
  5. Se abrirá tu navegador en: http://127.0.0.1:5500
  6. Cada vez que guardes el archivo (Ctrl + S), el navegador se recarga automáticamente 🎉
  7. Para detener el servidor, haz clic en el puerto (5500) en la barra inferior de VS Code

🧩 Extensiones Recomendadas Extra

Para Python:

  • Pylance - Análisis inteligente de código
  • Black Formatter - Formato automático
  • autoDocstring - Genera documentación
  • Python Debugger - Depuración avanzada

Para Productividad:

  • Material Icon Theme - Iconos bonitos
  • Prettier - Code formatter - Formateador universal
  • Path Intellisense - Autocompletado de rutas
  • Code Spell Checker - Corrector ortográfico
